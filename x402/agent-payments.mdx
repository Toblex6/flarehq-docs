**Mainnet x402 is disabled.** An ERC-8004 identity or funded Circle SCA does not enable paid API access.

## Four separate facts

| Value | Meaning |
|---|---|
| Registry ID | FlareHQ database identity used by owner-only wallet, policy, pay and treasury routes |
| ERC-8004 token ID | On-chain identity used by reputation and validation |
| SCA wallet | Circle Developer-Controlled treasury address |
| Payment EOA | Separate externally owned account capable of signing x402 authorizations |

**Circle SCAs cannot be x402 payers.** Do not treat identity headers or a token ID as a signature, ownership proof or payment. Do not assume `8004:{chainId}:{tokenId}` is an accepted identifier for every endpoint.

The owner-only agent wallet route uses the Registry ID and caller-control checks. Its provisioning behavior does not imply mainnet Gateway availability; never expose or request the payment EOA's private key.

## Configured testnet paid resources

Use the returned base64 `PAYMENT-REQUIRED` header as the source of network, asset, amount, recipient and verifier. Submit a compatible EOA authorization in the base64 `payment-signature` header. Settlement occurs before upstream delivery; a Gateway reference is not necessarily a mined hash.

Read [x402 protocol](/x402/overview) and [buyer convenience route](../api-reference/x402/pay.mdx) for the actual API boundary.

## Direct agent-to-agent payments are not x402

`POST /api/agents/{registryId}/pay` uses the caller-controlled agent payment EOA, spend-limit preflight and a direct native USDC transfer with receipt and recipient-credit checks. It is a different path from Circle Gateway paid API calls. End-to-end mainnet execution remains unverified.

ERC-8183 hiring and criterion-based job streams have their own protocol and funding dependencies. [Mainnet job actions are unavailable](/agents/erc8183-jobs); do not promise autonomous job earnings from wallet provisioning alone.
