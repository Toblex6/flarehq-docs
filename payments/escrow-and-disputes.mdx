## Mainnet status

Production escrow create, release and dispute endpoints return **503 `escrow_unavailable`**. No mainnet escrow is deployed or funded.

Escrow remains unavailable until the operator configures `ARC_MAINNET_ESCROW_ADDRESS` after deployment and verification. A testnet address must never be used on mainnet.

## Contract preparation

`FlareHQEscrow.sol` defines the escrow lifecycle. Available source code does not activate mainnet escrow.

The contract holds a deposit for a named beneficiary. Both parties confirm delivery to release it. Either party can dispute before expiry; the admin resolves to the beneficiary or depositor. An undisputed expired escrow can be refunded by the depositor. Admin transfer requires acceptance by the new admin and supports a Safe address.

The configured Safe must authorize its own dispute decisions. The existing server EOA signing path cannot sign for a Safe.
