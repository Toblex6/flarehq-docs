title: "Buyer EOA wallet availability"
sidebarTitle: "EOA wallet"
description: "Merchant-bound testnet buyer wallet routes; mainnet provisioning and deposits remain blocked."
---

**Mainnet calls are disabled.** `GET /api/x402/eoa-wallet/me` and authenticated GET/POST `/api/x402/eoa-wallet/deposit` return `503 gateway_mainnet_unavailable` before provisioning or deposit. Authentication ordering differs between the routes.

## Configured testnet GET /api/x402/eoa-wallet/me

Requires a resolvable merchant identity from its API key or merchant session. The route resolves or provisions that merchant's buyer EOA and returns `success`, `address`, `gatewayBalance` and `walletBalance`. The private key is never returned.

Balance retrieval currently falls back to string `"0"` on an upstream read failure; zero alone is not proof that the live balance was read successfully.

## Configured testnet POST /api/x402/eoa-wallet/deposit

Requires supported API-key/merchant authentication and a resolvable merchant identity. The body is `{ amount }`; the handler checks that it is present and passes `amount.toString()` to the SDK. It does not apply the shared strict USDC amount parser. Do not infer stronger amount validation from this documentation.

The server resolves or provisions the merchant's buyer EOA and asks the SDK to deposit from that EOA's on-chain funds. The response includes `depositTxHash`, optional `approvalTxHash`, `amountDeposited` and `explorerUrl`. Reconcile the actual receipt before treating a deposit as completed.

## Configured testnet GET /api/x402/eoa-wallet/deposit

Uses the same authentication wrapper and merchant-bound EOA resolution as POST, then returns `success`, `address` and the SDK's `balances` object. It is a balance operation, not a deposit.

A buyer **EOA** is separate from its Circle **SCA** treasury. Circle SCAs cannot be x402 payers. Do not send mainnet funds to a testnet Gateway address or assume a configured verifier enables mainnet deposits.

See [buyer paid-call route](./pay.mdx) and [x402 availability](/x402/overview).
