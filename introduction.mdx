FlareHQ connects merchant checkout and agent tooling to Arc through REST APIs. Checkout is non-custodial: the customer pays directly to the merchant wallet; FlareHQ never holds checkout funds. Do not extend that claim to every wallet service or to a contract-funded escrow.

## Mainnet availability

| Capability | Current status |
|---|---|
| Checkout and payment links | Live; the customer pays the frozen merchant wallet directly |
| Platform fees | Live; separate 25 bps merchant fee after a successful payment |
| ArcFlareStream | Deployed on Arc Mainnet; job streams still need a funded ERC-8183 job |
| CCTP bridging | Not yet proven end to end |
| ERC-8183 jobs | Unavailable; no mainnet protocol address is configured |
| Escrow | Unavailable pending deployment and verification |
| x402 | Disabled on mainnet |
| Payroll, scheduled payments and swaps | Not verified end to end |

A passing offline test, an API route or an agent identity does not establish successful mainnet settlement. Reconcile the receipt, parties, token, amount and recipient credit before fulfilling a payment. Read [mainnet availability](/payments/availability).

## Networks

| Network | EVM chain ID | Use |
|---|---|---|
| Arc Mainnet | `5042` | Production; real funds |
| Arc Testnet | `5042002` | Development with test tokens |

Production RPC is `https://rpc.mainnet.arc.io`; explorer is `https://explorer.arc.io`. USDC's ERC-20 interface is `0x3600000000000000000000000000000000000000`, with 6 decimals. CCTP domain `26` is **not** the EVM chain ID or the Bridge Kit destination name `Arc`.

Check the application's server-resolved [`/api/network`](https://flarehq.xyz/api/network) descriptor before authorizing a transaction. [Get Test Tokens](https://faucet.circle.com) only for Arc Testnet. Never substitute a testnet contract for a missing mainnet deployment.

## Authentication and identity

API keys and `merchant_token`, `consumer_token`, and `admin_token` sessions are distinct. Use the endpoint's supported credential and a wallet you actually control. Creating an own-wallet request does not move funds; sends, savings and requests to a foreign payout retain the relevant payment-code checks.

Agent identifiers are three labeled values: **Registry ID**, **ERC-8004 token ID**, and **SCA wallet**. Do not substitute one for another on owner-only policy, wallet or payment routes. Reputation is meaningful only when supplied by the backend; missing data is not a fabricated trust score.
